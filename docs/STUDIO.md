# Terra Studio

Terra Studio is the product: a local browser workbench for a seeded planet and
its history. It runs no cloud service, stores no database, and loads no remote
assets. The binary contains the server, the renderer and the entire client.

## Launch

```sh
cargo run --release -p terra-studio
```

The launcher:

1. binds an HTTP server to `127.0.0.1` on an ephemeral port,
2. generates a 128-bit random token,
3. opens `http://127.0.0.1:<port>/?t=<token>` in the default browser,
4. prints the URL as a fallback and keeps running until the process is stopped.

There is no terminal workflow after launch. The normal flags are `--port N`,
`--no-open` and `--help`; headless modes are documented in the README.

## Layout

- **Header** — seed, scenario preset, historical span, initial peoples, and the
  forge button.
- **Map stage** — ten switchable layers, a political year scrubber, civilization
  overlay toggle, zoom/pan and a Download map button.
- **Inspector** — click any map cell to read its biome, elevation, climate,
  discharge, productivity, species richness, carrying capacity, plate, stress,
  owner and recent local events.
- **World panel** — planet name, seed, cell count, land share, plates, rivers,
  lakes, climate means, surviving peoples, event count and traceability.
- **Peoples panel** — every civilization with color, population and territory.
  Clicking one filters the chronicle.
- **Chronicle** — event density chart, filters, paginated event list, cause panel
  with direct causes, breadth-first causal chains, explicit paths to physical
  facts, later consequences, and exports.

## Generation flow

1. The client posts a run request.
2. The server creates a job and starts one of at most two generation workers.
3. The worker reports stage and progress through the job record.
4. The client subscribes to `/api/events?id=...` over Server-Sent Events. If the
   stream fails, it falls back to polling `/api/job`.
5. On completion the client loads `/api/world`, then the map, the chronicle and
   the timeline in parallel.
6. The world stays in an in-memory cache (at most ten finished worlds). Older
   finished worlds are evicted first.

Progress is emitted after stages actually finish. No percentage is invented.

## Layers

| Layer | Content |
|---|---|
| Atlas | Biome palette with relief, rivers, plate boundaries |
| Elevation | Hypsometric ramp with hillshade |
| Plates | Categorical plate colors, boundary types |
| Biomes | Whittaker classes with relief |
| Temperature | Annual mean ramp |
| Precipitation | Annual total ramp |
| Rivers | Muted base, discharge-weighted rivers, lakes, deltas |
| Political | Desaturated base, territory tint, borders, cities, labels |
| Biodiversity | Species richness ramp |
| Stress | Convergent, divergent, transform and volcanic stress |

The renderer is a software rasterizer over the icosphere. It writes PNG with the
built-in encoder. Labels use a 5×7 bitmap font defined in the source; no font is
loaded at runtime.

## Political playback

The year slider requests the ownership snapshot nearest the chosen year. Moving
it re-renders the political layer (or any layer with the Civs overlay enabled).
Cities, capitals, borders and labels follow that snapshot, so you can watch
settlement spread, cities change hands and empires disappear.

## Cause panel

Selecting an event shows:

- **Direct causes** — state facts and earlier events.
- **Causal chain** — breadth-first graph with depth markers; every node is
  clickable.
- **Paths to physical facts** — explicit chains ending in measured state.
- **Later consequences** — events that cite the selection, directly or
  transitively.
- **Explain** — a deterministic paragraph generated by the same query API used
  by exports.

The panel is read-only. Selecting a cause navigates to that event.

## Security

- Listener bound to loopback only.
- Every `/api/*` request requires the token via `?t=`, `X-Token`, or
  `Authorization: Bearer`.
- Token comparison is constant-time over equal-length byte strings.
- CSP disallows inline scripts and remote resources; the client is one local
  script, one local stylesheet and one local SVG icon.
- Request headers are limited to 16 KiB, bodies to 64 KiB, URLs to 512 bytes and
  query values to 4 KiB. Unknown fields are rejected.
- No CORS headers are emitted. The Studio is not a public API.
- Exports set `Content-Disposition: attachment`.

# Changelog

All notable changes to Terra are documented here. The project follows a simple
`Added / Changed / Fixed` format and is versioned as `0.x` while the simulation
model evolves.

## [0.1.0] - 2026-11-25

### Added
- Cargo workspace with `terra-core`, `terra-history` and `terra-studio`.
- Standard-library-only project scaffold, MIT license and build targets.
